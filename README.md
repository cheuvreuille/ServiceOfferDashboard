# Identity.ai — Service Offer Dashboard

Dashboard web statique de pilotage commercial pour l’offre Identity.ai. Il permet de suivre les comptes cibles, les opportunités IAM4IA et IA4IAM, les statuts de pitch et les liens vers les ressources business. Chaque axe d’offre dispose d’un statut et de contacts Wavestone et client directement éditables dans le tableau.

## Lancer localement

```bash
python3 -m http.server 8000
```

Puis ouvrir [http://localhost:8000](http://localhost:8000). Les modifications sont enregistrées localement dans le navigateur.
